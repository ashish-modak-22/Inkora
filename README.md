# 📝 Inkora
 
### *Ink your thoughts. Anywhere. Anytime.*
 
A sleek, secure, and lightning-fast **native Android note-taking app** built with Kotlin — backed by a JWT-authenticated REST API for seamless cloud sync across devices.
